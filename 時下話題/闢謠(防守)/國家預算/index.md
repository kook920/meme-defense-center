## 財劃法/卓榮泰/覆議/國民黨/民眾黨/台灣奇蹟

```
卓榮泰院長被叫了一年多的「覆議院長」，行政院也被戲稱「覆議院」。

但所謂的「覆議」，其實是行政院一次又一次，把立法院這一年多通過的爭議法案退回，附上明確的問題點與理由，期待立委們能審慎看待，進行更好的修法。

結果呢？

你會發現，不只在野立委搞不清楚自己通過了什麼法案，同黨的縣市首長，在法案即將傷及自身利益時，還能毫無警覺地拍手叫好，笑得合不攏嘴。

水準低落的政客們，組成政黨、結為聯盟，控制了台灣的國會多數、縣市首長多數、議長多數與議員多數。

在這樣的結構下，台灣還能繼續前進，實在是個奇蹟。
```

## 財劃法/闢謠/早已預警/國民黨/民眾黨/

```
護航藍白財劃法，至少有三大錯：

1. 行政院沒提版本 → 錯。
👉 行政院在 2017、2021 都有提出「財劃法修正草案」，只是立法院沒有共識，審不下去。不能說「行政院從沒提」。

2. 公式問題突然才講 → 錯。
👉 財劃法公式本來就是 30 年前的設計，人口、稅收結構都變了。審議時試算過的數字是「各黨版本假設下的結果」，但問題在於「總額分不出去」，這是制度本身有缺陷，不是突然冒出來。

3. 民進黨消失不提 → 錯。
👉 不管是賴清德、柯建銘、蘇貞昌、鄭文燦，這些發言都是「支持修法」的態度，沒有人說「不改」。真正卡關的，是朝野無法達成共識，尤其各縣市爭資源，大家都要多分，結果就卡住。
‐----‐---------
你們好意思，斷章取義，張冠李戴，靠著人數優勢過這種爛法條，再栽贓行政院沒提過，真的是很無恥。
```
