# 闢謠(防守)/光電污染

## 水面太陽能/闢謠科普/抑制藻類/減少蒸發

```
🌞浮在水上的太陽能板有什麼用？真的會破壞飲用水嗎？

其實根據日本千葉的經驗，浮動式太陽光電反而能幫助解決台灣南部的乾旱問題喔！
來說說這兩個主要的好處：

✅ 好處一：幫助抑制水庫裡的藻類亂長
太陽能板像傘一樣遮住陽光，讓水面變暗，藻類就比較不會瘋狂繁殖。
特別是藍綠藻，太多會讓水變臭、變黃，淨水廠要花更多錢處理。
所以裝了太陽能板反而可以讓水庫水質變好，省下水費、省下處理成本。

✅ 好處二：減少水蒸發，讓水庫比較不會乾掉
水面被太陽照久了會蒸發，尤其是南部的水庫。
有了太陽能板當遮陽傘，就能減少水分流失，特別在乾旱季節超級重要！
而且太陽能板在比較涼的環境發電效果更好，水氣可以幫忙降溫，發更多電還不怕過熱。

📌 簡單來說：
✔️ 幫水庫擋太陽，水比較不會臭，也比較不會蒸發掉
✔️ 在對的地方蓋好、監控好，其實比不蓋還更環保！

當我們在討論要不要蓋「浮動式太陽能」時，應該看整體的利弊得失，不是一聽到「水庫」就急著開罵。
別被不完整的說法誤導啦！
```

## 綠能成長/燃煤漸少/綠燈天數成長/能源轉型/三黨共識

```
🔋 能源政策不是嘴炮，是看數據

蔡英文執政前（2016），全台全年供電綠燈只有 50 天；到了 2020 年，綠燈日數突破 300 天。

♻️⚡🔋 2022年：綠能發電比例超越核能
🏭 2024年：天然氣發電比例超越燃煤

這些都是扎扎實實的改變。

再生能源的確有挑戰，也有瑕疵，但不能因此否定整體轉型的成果。
不論你支持哪個黨，能源轉型已是台灣主流共識，三大政黨都承諾 2030 年綠電要達30%。

在氣候與國際情勢變化劇烈的時代，
穩定供電、發展綠能，不只是環保，
更是為了台灣的產業競爭力與國家安全。
```

## 水面太陽能/設置規範/比國外嚴格/定期檢驗/極端試驗把關

```
🌞 水面光電會污染水庫？別再被謠言唬了！

🔎台灣的光電設置，比美國、德國、日本、韓國還嚴！

🔰 第1層：制度最嚴格！
許多國家根本不規定水面型光電要做環評！
台灣早在2024年初就明訂：只要是在敏感區或山坡地達一定規模，就必須環評。
9月再次修法，要求中央與地方全面強化規範。

🔬 第2層：水質定期抽驗
嘉南滯洪池共進行 5次抽驗 × 14項指標 × 280項次，全數合格！
烏山頭水庫的水質，近5年都遠低於飲用水水源標準，甚至透明度名列前茅。
傳聞的「紅水」？查出是土壤腐植酸，不是光電污染。

🧪 第3層：極端模擬試驗
光電板泡進強酸（pH值2.88），仍沒超標！
檢測12項重金屬，全都符合飲用水標準。
實測 + 模擬雙軌並行，找不到任何污染證據。

📊 台灣的光電發展，是建立在「科學監測、制度設計」上的。
環境部也持續彙整國際資料、提升透明度，就是要讓大家看到科學、放心支持綠能。

🌱發展綠能和守護環境可以雙贏，請拒絕操作恐懼的假訊息！
```
