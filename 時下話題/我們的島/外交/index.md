## 美援/經濟/軍事/歷史

```
50年代的台灣一窮二白，還要養一百多萬中國逃難來台的軍人。

美國在1951-65年提供了15.2億美元的經濟金援（在那個年代是巨款），援助被用在各種民生建設，農業協助、還有一堆物資。
29.7億的軍事援助，台灣成為亞洲被美國軍援最多的國家之一。

1965年終止「贈與」，改為無息貸款及軍售，我國於2004年償還完貸款。

我國當年幾乎所有建設都有用到美援及美國專家協助蓋電力、交通、港口、通訊。（例如曾文水庫）

美國麵粉發到1968年，這也導致台灣變成開始吃麵包的飲食習慣，而美國麵粉袋（棉質）還被拿去只做內衣內褲，我爸當年都穿過。
也是美國援助才讓台灣撐過戰後物資通膨的狀況。

冷戰時期持續提供台灣軍事裝備，並讓台灣軍隊現代化。

美國對台灣的各項援助持續至今，連大家愛吃的愛文芒果都是50年代佛羅里達愛文莊園移植過來的⋯⋯

反中親美才是天經地義，何須問？
```

## 親中親美/國際陣營站隊/民主/大國博弈

```
當有人問「台灣為何不能在親中又親美」——聽起來理性，其實錯很大。讓我們用事實說話👇

🇺🇸 美國對台灣
1950～1976 年，美國提供台灣將近 7.8 兆元新台幣援助，軍事現代化、經濟穩定、十大建設，全靠這條命脈延續下來。至今還有《台灣關係法》、軍武銷售、安全保證。

🇨🇳 中國對台灣
0元援助。軍機擾台、網攻、外交打壓，挑明不排除武力犯台。中國從不承認台灣有「中立」的權利，眼中只有「收復」。

🎯 所謂中立，是站在哪裡？
一邊收美國的幫助，一邊幫中國講話、拚命模糊立場，在美國眼裡這叫背叛，不是中立。

台灣不是沒選擇，而是早就被時勢選上。
你想不站隊，但世界已經開戰。要選哪一邊，夠清楚嗎？
```
