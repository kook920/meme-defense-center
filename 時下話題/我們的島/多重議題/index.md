# 我們的島/多重議題

## 財政規劃/再分配/減稅/社會福利

```
《很多人沒發現，台灣這幾年其實超挺你！》
其實這幾年政府一直在做一件很重要的事：
讓有錢人多繳一點稅，讓一般人少繳一點甚至不用繳。

從蔡英文上任以來，免稅額、扣除額一路調高，明年還要再擴大，讓更多中低收入族群直接免繳所得稅。

你知道嗎？
台灣現在有 90% 的所得稅，是從最有錢的那 15%人身上收來的。
很多人覺得經濟好跟自己無關，但其實政府靠大企業、有錢人繳的稅，去支撐我們大家的社會福利、教育、建設，甚至國防安全。

📊 10年前的社會福利預算：4351億
📘 教育預算：3603億
明年預算是多少？
👉 社福 8318億、教育 5566億，幾乎翻倍！

簡單講就是：經濟有賺錢 → 政府有能力 → 就能多照顧大家。
而且這一套做法，能「減稅＋擴支」的，不是每個國家都做得到。
```
