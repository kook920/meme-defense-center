# 我們的島/多重議題

## 財政規劃/再分配/減稅/社會福利

```
這件事好像很多人不知道，台灣從蔡英文上任至今，就持續在做收入、稅制上的再分配，持續提高免稅額和扣除額，讓更多人不用繳所得稅，明年還會繼續擴大免繳所得稅的範圍，減低中低收入族群的負擔。

台灣九成的所得稅收來自15%高所得人口，很多人覺得經濟表現好與自己無關，事實上大部分的稅收來自有錢人、大企業，而這些稅收最後成為社會福利、公共建設、國防安全的經費來源。

十年前的台灣社福預算4351億、教育3603億，明年編列的總預算，社福8318億、教育5566億。

也正是要經濟表現好，政府才有餘裕可以提高免稅額、扣除額，讓更多人不用繳稅，但同時社會福利、教育預算還是能夠持續增加，這件事，沒有那麼多國家做得到。
```
