# 時事(進攻)/淡江大橋

## 國民黨心態/見不得台灣好/台北捷運/高鐵/淡江大橋

```
👎 國民黨人的特異功能：只要台灣變好，他們心情就不好。

當年：
台北市蓋捷運遭遇瓶頸，一時難以推動。趙少康說，應該把捷運沿線全部改成停車場。陳水扁不放棄，說「馬特拉不拉，我們自己拉」終於完成了台北捷運，如今大台北數百萬人口，都在享受捷運的方便乾淨迅速，包括趙少康在內的國民黨人，哪一個沒有身受其惠？

以前：
大陸工程公司董事長殷琪要建高鐵，只因為她挺陳水扁，馬英九就反對到底，唱衰說「高鐵會變廢鐵」叫大家不要搭。如今高鐵讓台灣成為一日生活圈，南來北往、準時準點，更促進經濟發展。包括馬英九在內，國民黨高層哪一個沒有身受其惠？

現在：
民進黨政府貫徹決心，好不容易蓋好《淡江大橋》，把它獻給全國人民，未來國民黨人不會身受其惠？國民黨對這一座世界級的偉大工程建設暨寶貴藝術品，不但一句好話也不肯說，反而拿一張紅布條拼命抹黑賴清德總統，抹煞所有人的貢獻。

從《台北捷運》到《台灣高鐵》以至《淡江大橋》，讓人看到國民黨醜陋又可惡的一面。
```
