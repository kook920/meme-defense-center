# 時事(進攻)/軍公教年金改革

## 軍公教年金改革/實質危機/國民黨/民眾黨/翁曉玲

```
📢 誰在掏空我們的未來？

當年朝野曾有共識推動 軍公教年金改革，就是為了世代正義
讓年輕公務員與年輕教師領得到退休金、看得見未來。
經過不小的陣痛期，年改終於上路，有效延後國家破產危機。

🔁 但現在，國民黨卻帶頭倒車！
在立法院，國民黨立委【翁曉玲】主導提出多項「反年改」法案，要取消年金改革成果，硬是讓改革成果倒退！

這些法案一旦強行通過，會帶來什麼後果？👇
💥 年金破產危機全都回來了：
1️⃣教育人員退撫基金最早將在 2040年破產
2️⃣公務人員退撫基金則在 2042年破產
3️⃣政府支出，5年內將暴增超過2,300億元！

換句話說：40歲以下的公務員、教師，根本領不到退休金！

📜 誰曾經支持年改？再來複習一次
國民黨前總統 馬英九 曾說：「年金改革今天不做，明天就會後悔」
吳敦義、江宜樺、關中 都公開支持年金改革
柯文哲、黃國昌 也明確表態支持改革、避免債留子孫

那現在呢？
國民黨帶頭提案掏空國庫，民眾黨也搖身一變當小藍，實質共犯！
```

```
這段話，想寫給會被這個法案影響到的你們👇

你們不是既得利益者，卻可能成為最大承擔者。「停砍年金」不是保障你們，而是把破產時點往前拉。等你們真的要退休，制度可能早就被掏空，退休金縮水、甚至領不到，風險全留給你們扛。

💸 給還在職場打拼、沒有年金保護的你
如果年金撐不住，政府只能用撥補救火。那不是抽象的數字，而是你我的納稅錢——平均每人近三萬元，拿去補貼已退休者。薪水比軍公教退休金還低的人，卻要一起買單，這真的公平嗎？

👨‍👩‍👧‍👦 給正在照顧孩子、長輩，期待公共支持的人
育嬰津貼、留職停薪、長照補助，哪一項不靠預算？當改革被推翻、財政被惡修，被犧牲的永遠是還沒發生、但真正需要的福利。不是政府不做，而是錢被提前花光了。

🌏 給所有關心未來的人
年金改革撐了八年，才換來一點穩定與世代公平。現在卻為了政治算計，一次三讀推翻成果，然後再回頭指責「政府不會執政」。如果這樣的決定不用負責，那國家的未來，究竟要誰來承擔？

這不只是軍公教的事，是所有還沒退休、還想好好生活的人共同的事。
```
