# 時事(進攻)/軍購

## 備戰止戰/日韓菲澳/真相揭露/中共威脅

```
欸大家真的要醒一醒，最近中國那邊在印太又軍機又假消息一堆，還有什麼灰色地帶的小動作，真的不是在跟我們開玩笑的。

說真的，台灣最危險的不是中國秀肌肉，是我們自己選擇放棄、覺得「算了啦」！
和平不是用低頭換來的，放棄自由跟主權根本換不到安全好嗎！

你看日本、韓國、菲律賓、澳洲都在升級自己的防衛，台灣這種前線位置更不能鬆懈。
藍綠吵歸吵，講再多，守住台灣讓它不被武力或其他招數吃掉，這才是我們每個台灣人的事！
```

## 台美軍購/網路嘲笑/反諷批評

```
看到一堆人在那邊酸「隱形戰機買了沒看到、錢都匯去哪了？」真的笑出來。

拜託，現在什麼年代了，軍購是分期付款、做到多少付多少，沒做就不付，你們到底哪來的幻想以為台灣「先把錢梭哈給美國」？

講得跟自己很懂國防一樣，結果連軍售怎麼付錢都不知道，看到延遲就立刻高潮大笑。
拜託，搞清楚遊戲規則再出來吵啦，不然只是讓人家看笑話而已。

越講越覺得，台灣缺的不是戰機，是常識。
```

## 台美軍購/網路嘲笑/反諷批評

```
每次只要提到軍購延遲，就有一群人跳出來嘲笑「隱形戰機去哪了哈哈」、「錢都被騙走了吧」。

拜託，你們是在看哪個平行宇宙？
台灣的軍購款根本都還躺在美國聯準會的信託帳戶裡好嗎？廠商沒做就拿不到錢！
結果一群人連付款機制是什麼都搞不清楚，就急著在那邊唱衰。

更扯的是，明明台灣遇到壓力期，你們第一反應不是關心，而是搶著嘲笑自己人，這種操作到底在幫誰？
中共還沒打來，你們先幫忙做心理戰，還做得特別賣力，真的離譜。
```
