## 財劃法/闢謠/早已預警/國民黨/民眾黨/

```
護航藍白財劃法，至少有三大錯：

1. 行政院沒提版本 → 錯。
👉 行政院在 2017、2021 都有提出「財劃法修正草案」，只是立法院沒有共識，審不下去。不能說「行政院從沒提」。

2. 公式問題突然才講 → 錯。
👉 財劃法公式本來就是 30 年前的設計，人口、稅收結構都變了。審議時試算過的數字是「各黨版本假設下的結果」，但問題在於「總額分不出去」，這是制度本身有缺陷，不是突然冒出來。

3. 民進黨消失不提 → 錯。
👉 不管是賴清德、柯建銘、蘇貞昌、鄭文燦，這些發言都是「支持修法」的態度，沒有人說「不改」。真正卡關的，是朝野無法達成共識，尤其各縣市爭資源，大家都要多分，結果就卡住。

你們好意思，斷章取義，張冠李戴，靠著人數優勢過這種爛法條，再栽贓行政院沒提過，真的是很無恥。
```

## 財劃法/國民黨/民眾黨/裝傻脫罪

```
國民黨現在的問題簡單講就是——假裝不懂「院版」是什麼。

📌 第一，院版不是隨便丟就好
行政院要提出院版，必須確保公式可算、錢分得下去，才能送進立法院。國民黨現在倒打一耙，好像院版拖久一點就是「無能」，但別忘了——你們自己的版本早就被專業官員點名「數百億根本分不出去」。換句話說，你們是隨便寫一份報表交差，還敢笑人家專業單位嚴謹？

📌 第二，歷史擺在那裡
民進黨喊修財劃法喊了好多年，過去你國民黨長期執政，怎麼從沒提過院版？六都成立、地方財政惡化，你們有認真面對嗎？現在反過來演「改革鬥士」，只是不想讓人記起你們過去的空白紀錄。

📌 第三，協商不是硬拗
在野黨版本公式有漏洞，專業部會提出問題，就是為了協商修正，避免讓縣市政府最後領不到錢。你國民黨卻把「專業審查」抹黑成「仇恨、鬥爭」，難道在你們的世界裡，專業意見只要跟你們不同，就是仇恨？

國民黨愛喊「院版」，卻假裝不懂院版要有專業基礎；愛喊「協商」，卻不接受專業修正。這種邏輯，根本不是幫人民爭取錢，而是幫自己爭取政治舞台。真正的無能，不是行政院審慎，而是國民黨的亂槍打鳥。
```

## 財劃法/國民黨/草率表決/都是別人的錯

```
國民黨在那邊喊「不提院版、巨嬰民進黨」，問題是——你們自己版本的財劃法根本是亂寫，連行政院都說公式算不下去。你們要地方拿錢，結果是公式不完整、數字兜不攏，這不是專業，是騙術。

📌 第一，誰才是無能？
財劃法修法，最需要的就是能不能「算得出來」與「發得下去」。行政院提出公式問題，代表要把國家財政規則講清楚，避免讓地方空歡喜。國民黨卻硬要裝作沒聽見，還說人家「討拍」，這才是草包邏輯。

📌 第二，誰才是消失？
民進黨多年來不斷喊修財劃法，行政院提出版本，甚至過去賴清德、林佳龍、鄭文燦、蘇貞昌都公開支持。反觀國民黨，過去在中央執政十幾年，財劃法有改嗎？六都成立、縣市財政惡化，是誰冷處理？現在反過來裝急先鋒？

📌 第三，誰才在玩政治？
你們的版本連行政部門專業官員都說「無法分配數百億」，結果卻硬推，目的就是要製造中央與地方對立，好把責任甩給執政黨。國民黨最愛玩這一套，結果最後出事還是地方百姓倒楣。

國民黨罵民進黨「巨嬰」，但自己提的法案是「假版」、算不出錢。專業在哪？責任在哪？如果只會做政治算術、不會做財政算術，那國民黨才是真正的巨嬰。
```
